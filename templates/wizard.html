RAG Service (optional)

Connect an external RAG service to enrich reviews with semantic repository context — architecture, dependencies, historical issues. Leave empty to skip.

Expected endpoints: GET /health and POST /retrieve-context

What the RAG service provides
When reachable, the reviewer sends each diff to the RAG service and receives back relevant context chunks (architecture docs, similar past issues, related components) ranked by semantic relevance. This context is injected into the prompt before Claude generates the review.

If the service is not configured or not reachable, the review runs normally without it.
